**Test Protocol:**

**Session 1: Baseline (30 pitches)**
1. Set up PitchTracker (cameras calibrated)
2. Set up TAG device (positioned per manufacturer specs)
3. Throw 30 pitches (or have pitcher throw)
4. **Manually record BOTH measurements:**
   - Open Google Sheet or Excel
   - For each pitch:
     - Column A: Pitch number
     - Column B: TAG device reading (from TAG app)
     - Column C: PitchTracker reading (from session export)
     - Column D: Difference (B - C)

**Example Data Collection:**
```
Pitch #  | TAG Device | PitchTracker | Difference
---------|------------|--------------|------------

4        | 73.8       | 73.5         | 0.3
...
30       | 72.9       | 73.1         | -0.2
---------|------------|--------------|------------
AVG      | 72.8       | 72.6         | 0.2 mph
```

**Analysis (After Session):**
```python
import pandas as pd
import numpy as np

# Load your manual data
df = pd.read_csv("validation_data.csv")

# Calculate metrics
mae = np.mean(np.abs(df['Difference']))
bias = np.mean(df['Difference'])
correlation = df['TAG Device'].corr(df['PitchTracker'])

print(f"Mean Absolute Error: {mae:.2f} mph")
print(f"Bias: {bias:.2f} mph")
print(f"Correlation: {correlation:.3f}")

# If MAE < 1.5 mph → Excellent
# If MAE < 2.0 mph → Good
# If MAE < 2.5 mph → Acceptable
```
