# TAG Sports Partnership - Executive Brief

**Date:** March 26, 2026
**Status:** Ready for Execution
**Read Time:** 3 minutes

---

## The Big Idea

**Partner with TAG Sports to create a consumer-to-facility ecosystem where TAG owns at-home practice tracking ($230 radar) and PitchTracker owns facility training analytics ($1,200 stereo vision).**

Athletes practice at home with TAG Sports → Join PitchTracker facilities → Data flows seamlessly

---

## Why This Works

### Complementary Products (Not Competing)

| TAG Sports | PitchTracker |
|-----------|-------------|
| Consumer market | Facility market |
| $230 portable radar | $1,200 stereo vision |
| Speed only | 3D trajectory + movement + location |
| 2-5 min setup | 30-60 min setup |
| Mobile app | Desktop app |
| Individual athletes | Multi-pitcher facilities |

**Different markets, same athlete journey.**

## Partnership Benefits

### For TAG Sports
✅ **Referral revenue:** $90K-135K/year (10-15% of facility revenue)
✅ **Competitive moat:** Exclusive integration vs. Pocket Radar
✅ **Higher LTV:** TAG users who join facilities are 4-9× more valuable
✅ **Network effects:** More facilities → more valuable to consumers

### For PitchTracker
✅ **Qualified leads:** TAG's 10K+ users are validated tracking enthusiasts
✅ **Near-zero CAC:** TAG handles consumer marketing, we get facility pipeline
✅ **Differentiation:** Only TAG integration exists (vs. Rapsodo, TrackMan)
✅ **Brand awareness:** Piggyback on TAG's D2C marketing

### For Athletes
✅ **Data continuity:** Practice data (TAG) flows into facility training (PitchTracker)
✅ **Affordable path:** $230 + $75/month vs. $3K Rapsodo
✅ **Complete picture:** Speed at home + 3D trajectory at facility

## Integration (MVP - 2-4 Weeks)

**TAG Sports Side:**
- Add "Export to PitchTracker" button
- Generates JSON file (athlete data, sessions, pitches)

**PitchTracker Side:**
- Add "Import TAG Sports Data" feature
- Displays practice history in pitcher profiles
- Shows in coach dashboard

**User Flow:**
1. Athlete exports TAG data (one click)
2. Emails or transfers file to facility
3. Coach imports into PitchTracker
4. Practice history visible before first facility session

**Later (Phase 2):** Cloud sync eliminates manual transfer

## Risks & Mitigation

**Risk:** TAG Sports doesn't respond or declines
**Mitigation:** Solo GTM remains viable (baseline). Partnership is accelerator, not requirement.

**Risk:** Integration doesn't drive adoption
**Mitigation:** Pilot first (validate demand before full buildout). Athlete incentives.

**Risk:** Validation shows poor accuracy
**Mitigation:** Diagnose, improve, narrow operating envelope. Be transparent.
