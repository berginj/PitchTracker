# PitchTracker Support

## Before opening an issue

Review:

- [Current Status](docs/CURRENT_STATUS.md)
- [Quick Start](docs/QUICK_START.md)
- [FAQ](docs/FAQ.md)
- [Troubleshooting](docs/user/TROUBLESHOOTING.md)
- [Testing Help Needed](docs/TESTING_NEEDED.md)

The current v2.0.0 release has no installer asset, and physical speed/location
accuracy is not yet validated for public claims.

## Choose the right channel

- Use a standard [GitHub issue](https://github.com/berginj/PitchTracker/issues)
  for reproducible software bugs or bounded feature requests.
- Use the Validation Report form for camera, setup, synchronization, installer,
  or physical-reference results.
- Use the Pilot Feedback form for operator and facility workflow feedback.
- Use [private vulnerability reporting](https://github.com/berginj/PitchTracker/security/advisories/new)
  for suspected security issues.

## Include useful evidence

- exact version or commit;
- Windows and Python versions where applicable;
- camera models and anonymized identities;
- requested and negotiated modes;
- reproduction steps and exact error text;
- attempted/accepted/rejected/unmatched counts with denominators; and
- relevant artifact hashes or filenames.

Keep athlete media, facility details, raw hardware serials, calibration files,
secrets, and unreviewed logs private.
